# NIMA: Эпохи — инструкция для агента (Antigravity и других)

Этот файл — передача дел. Прочитай его целиком до первого действия.

## 1. Что это

Один общий цифровой океан, который круглосуточно эволюционирует на сервере. Существ никто
не рисует вручную: тела собираются из генов, роли (травоядные, хищники) измеряются, виды
возникают и вымирают сами. Живой сайт: https://emergentia.cloud/nima/

Владелец проекта говорит по-русски и делегирует технические решения («решай сам, мне важен
результат»). Отвечай по-русски, коротко и честно: что сделано, что проверено, что нет.

## 2. Доступ

- Сервер: VPS `srv1629746` (1 vCPU, сильная «кража» CPU гипервизором — до 75% под нагрузкой).
  Подключение по SSH под root; ключ доступа выдаёт владелец, в репозитории его нет.
- Код на сервере: `/opt/nima-epochs` — это и есть git-репозиторий
  https://github.com/ahdpe/nima (ветка `main`, `gh` на сервере авторизован).
- Node.js 22, без внешних зависимостей (только стандартная библиотека).

## 3. Где что лежит

| Путь | Что |
|---|---|
| `/opt/nima-epochs/engine.mjs` | процесс-движок: шаг мира 5 Гц, сохранения, кадры для клиентов |
| `/opt/nima-epochs/server.mjs` | HTTP + WebSocket, порт 8090 (только 127.0.0.1), запускает движок через fork |
| `lib/world.mjs` | вся физика мира |
| `lib/genome.mjs` | геном, фенотип, мутации, сигнатура вида |
| `lib/params.mjs` | все константы физики |
| `lib/environment.mjs` | свет, климат, архипелаг (7 островов, мир 1536×1536) |
| `lib/frames.mjs` | бинарные кадры для браузера (тела kind 8, растения kind 7) |
| `lib/chronicler.mjs` | ИИ-летописец: имена видов, заметки, газета, наряды видов (ИИ-художник) |
| `lib/demiurge.mjs` | ИИ-демиург: раз в сутки придумывает 1–2 вида-переселенца и погоду |
| `public/` | страница: `app.js`, `render.js` (WebGL2), `bodies.js` (облик тел), `museum.js`, `life.js`, `i18n.js`, `about-*.html`, `math-*.html` |
| `test/` | тесты (`npm test` = `node --test test/*.test.mjs`) |
| `deploy/` | systemd-юнит и куски nginx |
| `/var/lib/nima-epochs/` | **живой мир**: снимки (checkpoint), `chronicle.json`, `demiurge.json`, `discoveries.json`, `events/fossils/history.jsonl`, `status.json` |
| `/etc/nima-epochs.env` | секреты и лимиты ИИ (root, 600). **Никогда не копируй в код и не коммить** |
| `/var/backups/nima/` | резервные копии перед каждой выкладкой |
| `/etc/nginx/sites-available/emergentia.cloud` + `/etc/nginx/snippets/nima-subpath.conf` | прокси `/nima/` и `/nima/ws` → 127.0.0.1:8090 |

Служба: `systemctl status|restart nima-epochs` (пользователь `nima-epochs`, MemoryMax 512M,
CPUQuota 40%). Логи: `journalctl -u nima-epochs`. Здоровье: `curl -s localhost:8090/health`.

Полезные адреса API: `/api/news`, `/api/museum`, `/api/tree`, `/api/papers`, `/api/demiurge`,
`/api/timelapse`. Сводка мира приходит по WebSocket `/ws` первым текстовым сообщением.

## 4. Как вносить изменения (обязательно)

1. **`public/` раздаётся вживую.** Любая правка файла сразу видна посетителям. Делай правки в
   копии (например, `cp -a public /tmp/stage`), проверяй, потом копируй обратно.
2. Проверка синтаксиса браузерных модулей — только так:
   `node --input-type=module --check < public/app.js`
   (обычный `node --check` однажды пропустил ошибку и сломал сайт).
3. Тесты: `cd /opt/nima-epochs && nice -n 19 npm test` — все должны проходить (сейчас 29).
4. Перед изменением физики или выкладкой — резервная копия:
   `ts=$(date +%Y%m%d-%H%M); mkdir -p /var/backups/nima/epochs-X-$ts && cp -a /var/lib/nima-epochs/. /var/backups/nima/epochs-X-$ts/`
5. Изменения в `lib/`, `engine.mjs`, `server.mjs` требуют `systemctl restart nima-epochs`.
   Мир сохраняется при остановке и продолжает ровно с того места. Открытые страницы сами
   перезагрузятся (сервер шлёт хеш сборки).
6. Новые поля генома добавляй с миграцией: см. `settlePlan()` в `genome.mjs` и блок
   `restore()` в `world.mjs` (старые снимки должны грузиться, сигнатуры дорастают до `SIG`).
7. Вещество сохраняется (тест проверяет до 1e-9): всё, что появляется в мире, берётся из
   растворённого питания или донного осадка.
8. Опыты над физикой — на **копии** живого мира, с низким приоритетом, чтобы не мешать миру:
   `EPOCHS_WORLD=1536 EPOCHS_ISLANDS=7 nice -n 19 node my-experiment.mjs` (образец: загрузить
   снимок через `new Storage('/var/lib/nima-epochs').load()` и `World.restore(...)`).
9. Никогда не убивай процессы через `pkill -f <шаблон>` — шаблон совпадает с твоей же
   командной строкой и убивает оболочку. Ищи PID через `ps` и убивай по номеру.
10. Безголовые тесты отрисовки (Playwright) не должны открывать карточки видов на живом
    сайте программно — иначе тестовый браузер запишется «первооткрывателем» вида.
11. Коммит после работы: `git add -A && git commit && git push` (без секретов; `.gitignore`
    исключает `runs/`, `screenshots/`, `sound-demos/`).

## 5. ИИ и деньги

Ключ Venice — в `/etc/nima-epochs.env` (`VENICE_API_KEY`). Там же:
`EPOCHS_AI_DAILY_USD=0.20` (летописец, модель qwen3-235b, реально ~5 ц/сутки),
`EPOCHS_DEMIURGE_USD=0.20`, `EPOCHS_DEMIURGE_MODEL=claude-sonnet-5-5` (~2 ц за сеанс, раз в сутки).
Каждый платный запрос резервируется в журнале на диске **до** отправки; превышение счёта
останавливает ИИ (`halted`). Жёсткие потолки зашиты в коде (20 и 30 центов).
ИИ только выбирает значения из словаря мира и пишет тексты; всё проверяется до попадания в мир.

## 6. Принципы проекта (не нарушать)

- Мир детерминирован и честен: никаких «рисованных» существ, кроме проверенных
  переселенцев демиурга; всё дальнейшее решает отбор.
- Внешний вид следует из генов (симметрия, органы, форма роста, пигмент). Чистое оформление
  (блики, снег, анимации рождения/смерти, наряды художника, «шум развития» растений)
  явно перечислено в «О проекте» — при добавлении нового оформления допиши туда.
- Любая новая механика должна иметь и выгоду, и цену; проверяй баланс на копии мира.
- Документация для посетителей: `public/about-ru.html`, `about-en.html`, `math-ru.html`,
  `math-en.html` — обновляй формулы вместе с кодом.
